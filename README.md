# ResearchTrail

중단한 문헌 과업의 기록과 확인한 다음 작업을 되찾는 학부생용 앱을 개발한다.

## 화면 실행

```sh
python3 -m http.server 5500 --directory web
```

브라우저에서 http://127.0.0.1:5500/ 을 연다. VS Code Live Server에서는 web/index.html을 연다. 가입 없이 예시와 내 타임라인을 사용할 수 있고 기록은 해당 브라우저·주소에 저장된다. 현재 AI 후보는 규칙 기반 예시이며 서버 연동은 개발 전이다.
