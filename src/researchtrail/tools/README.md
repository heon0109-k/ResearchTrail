# LLM 도구

ResearchTrail은 LLM에 데이터 저장이나 외부 작업을 실행할 수 있는 도구를 제공하지 않는다. 설계 근거는 [아키텍처 3.1절](../../../docs/ARCHITECTURE.md#31-llm에-주는-도구-없음)에 정리돼 있다.

사용자가 다음 할 일 후보를 확인하고 저장 버튼을 누르면 브라우저가 확정한 내용을 저장한다. 규칙 기반 후보의 확인·저장 처리는 [next-action.js](../../../web/js/next-action.js)에 있다. 확인 전 초안이 기존에 저장한 할 일을 바꾸지 않는 동작은 [후보 초안 테스트](../../../tests/web_persistent_candidate.test.cjs)에서 확인한다.

LLM이 호출할 수 있는 도구가 없으므로 별도 도구 계약 테스트 파일은 두지 않는다.
