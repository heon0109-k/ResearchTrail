# 예시 데이터

앱의 **예시 먼저 보기**를 누르면 [core.js](../../web/js/core.js)의 `loadSample`이 예시 타임라인을 불러온다. 예시 논문 정보는 [sample-papers.js](../../web/js/sample-papers.js)에 있다. 예시 PDF는 [논문 자료 폴더](../../web/assets/papers/)에 있으며, 파일 목록은 [manifest.json](../../web/assets/papers/manifest.json)에서 확인할 수 있다.

규칙 기반 기능을 평가하는 데 쓰는 합성 입력과 기대 결과는 [Evals 데이터셋](../../evals/evalset.jsonl)에 있다.
