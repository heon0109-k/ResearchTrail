# 제품 화면의 렌더 함수 출력 비교

기준 커밋 `0d9d534`의 브라우저 로컬 함수와 현재 작업 트리의 계정 함수를 각각 실행했다. 두 경로에 같은 합성 논문 두 편, 태그 두 개, 같은 날짜·읽기 상태·링크·PDF 파일명을 사용했다. 계정 경로는 인증 응답 대역의 논문 행을 실제 계정 어댑터로 읽었다.

표의 수는 캡처한 HTML에 있는 button, input, select, textarea 및 버튼 역할을 가진 div/g의 개수다. 공통 문구는 양쪽 HTML에 실제로 있었던 검사 대상 문구다. CSS로 감춘 요소도 포함한다. 데스크톱(1440 × 900)과 휴대폰(390 × 844)은 렌더 함수의 분기 입력이며, 브라우저가 계산한 크기나 PNG가 아니다. 리더는 실제 PDF 파일 대신 34쪽짜리 PDF.js 문서 대역을 사용해 원래 도구 모음 함수를 실행했다.
